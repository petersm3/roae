# DOC_GATE_FIGURE_ALLOWLIST.txt - GATE 3b (scripts/doc_gates.sh retract-figures)
#
# GATE 3b has NO automatic exemption. Not a filename allow-column, not a changelog-row
# rule. Every legitimate occurrence of a registered retracted FIGURE is one explicit row
# here, and anything not listed is a [FAIL]. That is deliberate and it is measured: a
# changelog exemption would have hidden this gate’s first live finding, TR-2 v1.12’s
# "2.0σ", which sat inside a revision row and had been superseded for a day.
#
# CONTENT-ANCHORED, NOT LINE-ANCHORED (GATE 5’s A8 lesson). The anchor is a fixed
# substring that must appear on the SAME LINE as the figure. Line numbers drift on every
# insertion above them; a sentence fragment does not. An anchor that stops matching is
# re-printed as [note] every run - the drift audit - so a row can never quietly go dead.
#
# LIMIT, stated so it is not rediscovered the hard way: the anchor must be on the FIGURE’S
# OWN LINE. Where a supersession clause is in the same paragraph but on the next line
# (TR-9’s draft-stage note), the row says so in its reason column.
#
# Format, TAB-separated, 5 fields:
#   file <TAB> figure <TAB> same-line anchor <TAB> class <TAB> why
#
# CLASSES
#   meta-mention  the text quotes the figure in the act of recording its correction.
#                 Legitimate; flagging it would punish the fix.
#   historical    a dated record that was TRUE when written and was later overtaken.
#                 Legitimate; rewriting it would falsify the record.
#   literal       (2026-08-07, with the reports/evidence/ non-markdown corpus extension;
#                 the name is GATE 18's, same meaning) the characters coincide with a
#                 registered figure but denote a DIFFERENT quantity — e.g. a histogram
#                 bin row in a machine-output log. Legitimate; the retracted figure is
#                 not being restated, the string is a fixed-string collision. Neither
#                 sibling class fits: it narrates no correction, and it was never
#                 "overtaken" — it is still true.
#   anything else is printed as [OPEN] every run: a live restatement that has been
#                 admitted only so a NEW one fails the build. There are none today.
