# DOC_GATE_SELFTEST_INSTRUMENTS.txt — every function defined inside doc_gates.sh's
# --selftest region, and the assertion that proves it. Consumed by doc_gates.sh GATE 15.
#
# WHY THIS FILE EXISTS. `_selftest_revert` shipped at fbdbe26 with no fire-proof, in the one
# file whose own header records GATE 8 shipping a one-directional comparison behind a
# hand-taken proof. It was caught only because someone checked a commit message's claim
# against a run. That is the THIRD instance of one class — GATE 8's hand-taken proof, GATE
# 4b's shared dispatch, and now this — so the answer is not more care. A new instrument in
# the harness must now be DECLARED here, naming the assertion that proves it, or GATE 15
# fails.
#
# FORMAT: `function<TAB>proof-label<TAB>claims<TAB>note`, one per line. `#` comments and
# blank lines ignored. Must end with a newline (the support-file preflight enforces that).
#   proof-label = a literal string that must occur in scripts/doc_gates.sh — normally the
#                 label of the assertion that exercises the function.
#   proof-label = NOT-PROVEN-IN-HARNESS for a function that genuinely cannot be asserted
#                 from inside a live self-test. The note must then say why and where the
#                 external proof is recorded. GATE 15 prints these every run; they are
#                 declared gaps, never silence.
#   claims      = exactly `kind=<K> callers=<N>`, the two MACHINE-READ facts (LEG 3, round 9
#                 items B8 + B3). The note is prose and is still read by nothing.
#   note        = what the row means, including what the callers=N number is made OF, which
#                 no count computes.
#
# THE CLAIMS COLUMN — kind=<K>. GATE 15 LEG 3 checks each kind, and requires the STRONGEST
# satisfied kind to be declared (a row cannot downgrade itself to escape the strict check):
#   INVOCATION  the proof-label is the FIRST QUOTED ARGUMENT of a call to the declared
#               function: some line of doc_gates.sh matches `^[ \t]*<fn>[ \t]+"<label>"`.
#               This is the claim caveat (1a) wants, because a label satisfied only by a
#               comment or by another assertion's mutation string cannot take this form.
#   BLOCK       the label occurs within 8 lines BELOW a call site of the function. The three
#               one-line wrappers genuinely have this shape. LEG 3 prints the MEASURED
#               distance for each on every run, so a window that starts creeping is visible
#               rather than absorbed. NO PER-ROW DISTANCE IS QUOTED HERE, AND THAT IS A
#               CORRECTION (round 12 drain-3, item `R11`): this paragraph used to freeze
#               all three as "today: ...", and `f5fac73` then moved one of them without
#               touching this file, so the header disagreed with the run it claims to
#               summarise. Read them off LEG 3's [ok] line; that line is the authority and
#               this one cannot be.
#               THE DISTANCE IS TO THE ASSERTION'S REPORT LINE, and that is what `f5fac73`
#               changed. It used to be the FIRST QUALIFYING OCCURRENCE, which for
#               _selftest_revert was the `grep -q 'A1 snapshot probe'` guard — the marker
#               text the assertion searches for, sitting one line ABOVE the
#               `[ok]   A1 snapshot` echo. A row proven by a string the harness never
#               prints is not proven, so LEG 3 now binds on the echo and the printed
#               distance for that row grew by one. The superseded reading — "the number
#               LEG 3 prints is the nearer one, and reading it as distance to the report
#               line would be wrong by one" — is recorded because it was on file and a
#               reader may have carried it away, not because it still holds.
#   EXTERNAL    paired with NOT-PROVEN-IN-HARNESS. Both directions are enforced: an EXTERNAL
#               row may not name an in-harness label, and a NOT-PROVEN-IN-HARNESS label may
#               not be declared any other kind.
#
# THE CLAIMS COLUMN — callers=<N>, counted by ONE rule, stated here so a row author can
# compute it by hand: occurrences of the function name in COMMAND POSITION — at line start,
# after `$(`, after `&&` / `||` / `;` / `|` / `then` / `else` / `do`, or opening a `trap`
# handler string — on lines that are not comments, excluding the function's own definition
# line. Nothing else counts as a call.
#
