# DOC_GATE_SELFTEST_INSTRUMENTS.txt — every function defined inside doc_gates.sh's
# --selftest region, and the assertion that proves it. Consumed by doc_gates.sh GATE 15.
#
# WHY THIS FILE EXISTS. `_selftest_revert` shipped at fbdbe26 with no fire-proof, in the one
# file whose own header records GATE 8 shipping a one-directional comparison behind a
# hand-taken proof. It was caught only because someone checked a commit message's claim
# against a run. That is the THIRD instance of one class — GATE 8's hand-taken proof, GATE
# 4b's shared dispatch, and now this — so the answer is not more care. A new instrument in
# the harness must now be DECLARED here, naming the assertion that proves it, or GATE 15
# fails.
#
# FORMAT: `function<TAB>proof-label<TAB>note`, one per line. `#` comments and blank lines
# ignored. Must end with a newline (the support-file preflight enforces that).
#   proof-label = a literal string that must occur in scripts/doc_gates.sh — normally the
#                 label of the assertion that exercises the function.
#   proof-label = NOT-PROVEN-IN-HARNESS for a function that genuinely cannot be asserted
#                 from inside a live self-test. The note must then say why and where the
#                 external proof is recorded. GATE 15 prints these every run; they are
#                 declared gaps, never silence.
#
# WHAT GATE 15 CANNOT SEE, stated rather than implied — this is the load-bearing caveat and
# it should be read before trusting a green run:
#   (1) It checks that the function EXISTS and that the named label EXISTS. It CANNOT check
#       that the named assertion actually exercises the function. A row pointing at a real
#       but unrelated label passes. This is bookkeeping with a spell-check, not a coverage
#       prover, and calling it more than that would be the false clear it was written to
#       prevent.
#   (2) It covers the --selftest region only. Helper functions in gate bodies (check_pair
#       inside gate_cli, the _norm/_cmp family inside assert_gen_fires) are out of scope:
#       they are gate implementation, and the gates have their own fire-proofs.
#   (1a) The label search is over the WHOLE of doc_gates.sh, so a label that occurs only in
#       a comment, or only inside another assertion's mutation string, satisfies it. Not
#       hypothetical: GATE 15's own "a row naming an assertion nobody wrote" fire-proof
#       FAILED on its first harness run because the literal it injected was thereby written
#       into doc_gates.sh, and the fire-proof satisfied the condition it was testing for.
#       It now assembles its substitute label from fragments and asserts the assembled form
#       is absent before injecting.
#   (3) It cannot tell a good proof from a weak one. `assert_fires`'s anchor-moved branch is
#       exercised by nothing; the row says so in prose that no machine reads.
_selftest_revert	A1 snapshot	The snapshot half: a reverted edit must be readable back out of refs/doc-gates/selftest-revert@{0} AND the reflog must have GROWN. Shipped at fbdbe26 with NO assertion at all and a commit message claiming a property (--create-reflog) it did not have; that is the defect this whole file exists to generalise.
_selftest_release	NOT-PROVEN-IN-HARNESS	The signal half cannot be asserted from inside: a case that TERMs the self-test kills the harness that would report on it. Proven EXTERNALLY and non-vacuously on 2026-08-02 (marker appended from outside a live run, SIGTERM sent, rc 143, marker gone, lock gone, git status clean). An earlier attempt TERMed before any mutation existed and was vacuous; the recorded proof is the second one. This row is why the table permits NOT-PROVEN-IN-HARNESS rather than forcing a fake label.

assert_fires_why	GATE 3 retracted phrasing	The workhorse: ~40 callers, every one of which fails if the WHY line does not name the injected thing. NOT exercised: its own anchor-moved branch.

scratch_appendonly	GATE 10b vs history (a line of the OLDEST committed version deleted)	Builds the scratch worktree GATE 10b's history legs mutate.

_g15	GATE 15 an undeclared instrument in the --selftest region	One-line wrapper that points GATE 15's read-only source seam at a mutated COPY of doc_gates.sh; the live script cannot be mutated safely because bash is executing it (task #77).
