# Archived visualization pages

These pages describe figures of the **enumerated slices** — the d3 560T canonical (`9a968fa2…`) and the d3 100T canonical — made before the compiled superspace (TR-12) became the project's centre: the four PCA projections ([`viz_pca.md`](viz_pca.md)), the growth curve and the 560T re-run telemetry panels ([`viz_graphs.md`](viz_graphs.md)), and the specification of two figures drawn for a document that has no public counterpart ([`viz_narrative.md`](viz_narrative.md), still HELD). The images they describe stay under `runs/<run-id>/viz/`; the tools that made them are [`viz/visualize.py`](../visualize.py) and [`viz/growth_curve.py`](../growth_curve.py). They are kept because published documents cite them and because the run directories they explain are part of the record; nothing here is current guidance. For the figures the reports use today start at [`../README.md`](../README.md).
